# CIFAR-100 Image Classification Using CNN and VGG-16

## Overview

This project explores image classification using deep learning on the CIFAR-100 dataset. It implements and evaluates two convolutional neural network architectures: a custom CNN and VGG-16.

## Models Implemented

- **Custom CNN:** A convolutional neural network designed for image classification.
- **VGG-16:** A deep CNN architecture with multiple convolutional blocks and fully connected layers.

## Dataset

The project uses the CIFAR-100 dataset, which contains 60,000 color images across 100 classes.

- Training images: 50,000
- Test images: 10,000
- Original image size: 32 × 32 pixels
- Number of classes: 100

## Technologies Used

- Python
- TensorFlow / Keras
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## Project Workflow

1. Load the CIFAR-100 dataset.
2. Preprocess and normalize the images.
3. Encode the class labels.
4. Build the Custom CNN and VGG-16 models.
5. Train the models using training data.
6. Monitor performance using validation data.
7. Evaluate the models on the test dataset.
8. Compare model performance using accuracy and loss.
